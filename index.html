UA Secure Computing Lab

Department of Computer Science & Engineering · University of Arizona · Tucson, AZ

The Secure Computing Lab at the University of Arizona develops practical, robust, and scalable systems infrastructure for cloud and edge applications. We draw on advances in trusted hardware, applied cryptography, and principled system design to build defensive solutions that work at real-world scale. Our work spans confidential computing, secure storage, network security, and emerging challenges in AI infrastructure and software supply chains.

The lab is led by Prof. Quinn Burke, Assistant Professor in the Department of Computer Science at the University of Arizona. We are always looking for motivated graduate students — see the Prospective Students page for details.

Research Areas

Confidential Computing

Leveraging trusted execution environments (TEEs) to protect cloud workloads and enable verifiable computation on sensitive data.

Secure Cloud & Edge Storage

Efficient integrity checking, encrypted file systems, and auditable state management for cloud and edge storage platforms.

Network Security

Security in software-defined networking (SDN) and cloud environments, including IP address allocation, load balancing, and multilevel security networks.

Observability & Telemetry

Intrusion detection, system monitoring, and tamper-evident telemetry pipelines for threat detection and response.

Secure AI Infrastructure

Agent sandboxing, secure AI runtimes, and trustworthy infrastructure for machine learning workloads and automated pipelines.

Software Supply Chain Security

Verifiable and tamper-evident system designs that protect the integrity of software from build to deployment.
